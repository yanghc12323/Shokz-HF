## 1. 本周任务要求

mentor 给出的 W2 任务可以拆成五件事：

1. 参考论文，明确耳朵模型需要被处理成什么样的形态。
2. 明确划分耳朵区域所需要的特征点。
3. 将由特征点划分出来的三维三角区域投影到二维平面。
4. 在二维平面上进行降采样，并保证每个区域采样点数量相同。
5. 根据选取的特征点计算相关特征值。

我们目前的工作正是围绕这五件事展开，并且已经形成了一条可以重复运行、可以输出检查结果的主流程。

## 2. 我们现在做到了什么

我们已经把每个受试者原始的三维耳朵网格，按照人工标注的耳部特征点切成若干三角区域。每个三角区域都会被展开到统一的二维标准三角形中，再在这个二维三角形里用相同规则采样，最后映射回三维空间。

这样做的目的，是让不同受试者在同一个耳朵区域上拥有：

```text
相同的区域编号
相同的采样点数量
相同的点顺序
相同的三角面连接方式
```

这一步是后续做平均耳和形态统计分析的前提。

## 3. 当前采用的处理流程

当前主线不是简单地从原始网格上随便取点，而是采用更接近论文方法的局部区域重建思路。

完整流程如下：

```text
输入：
  原始三维耳朵网格
  人工标注的耳部特征点
  区域划分表

处理：
  1. 将特征点吸附到最近的网格顶点
  2. 根据三个特征点定义一个三角区域
  3. 在网格表面寻找三条边界路径
  4. 提取边界围成的局部耳朵区域
  5. 将这个三维区域展开到二维标准三角形
  6. 在二维标准三角形中按固定规则采样
  7. 把二维采样点映射回三维耳朵表面
  8. 输出统一点序和统一面片结构的区域结果
```

这个流程的意义是：不同人的原始耳朵网格虽然点数不同、面片不同，但经过这一步后，可以被整理成可以横向比较的数据结构。

## 9. 当前发现的主要问题

当前问题集中在区域划分的稳定性上，尤其是 T009。

T009 仍表现为：

```text
patch_face_count = 195
unmapped_count = 15 / 45
status = FAIL
```

更可能的原因包括：

1. T009 的三个特征点组合在不同耳形上不够稳定。
2. 网格表面的最短路径可能走了不符合解剖结构的捷径。
3. 三条边界围出的区域可能过窄、过小或方向不正确。
4. 某些区域需要进一步拆分，或者更换特征点组合。

## 10. 为什么暂时不建议直接调参数

当前不建议简单提高采样精度或放宽质量检查标准。

原因如下：

1. 当前问题不是采样点太少，而是部分区域本身没有被正确提取出来。
2. 如果区域没有覆盖完整耳部表面，提高采样点数量只会产生更多无法映射的点。
3. 如果放宽质量检查，后续统计分析会混入不可靠数据。
4. 对无法映射的点强行插值，会掩盖真实的问题。

因此当前更合理的优先级是：

```text
先优化区域划分，再考虑参数调整。
```
