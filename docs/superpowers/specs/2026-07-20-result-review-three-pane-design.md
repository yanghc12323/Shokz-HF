# 结果复核三分区布局设计

## 目标

消除结果复核页面文字和表格拥挤重叠，并将 PCA Score 作为独立、可滚动的子区域展示。

## 布局

- 左侧固定宽度信息栏（约 360 px）：结果复核标题、PCA 摘要、PCA 指标表、输出入口、样本选择、状态与原因、图层/region 控制。
- 右侧为垂直分割区：上方 PCA Score 面板（标题、说明、可滚动表格），下方为 3D 模型查看面板。
- 右侧上下区域默认按 42% / 58% 分配；用户可通过分隔条临时调整。

## 交互与适配

- PCA Score 不再挤在左侧；数据加载、列、格式化和缺失提示保持不变。
- 3D 查看器获得稳定、独立的最小高度，避免被表格挤压。
- 在最小窗口尺寸下，右侧以滚动表和可收缩分割区处理内容，不使用绝对定位，因而不会发生文字层叠。
- 既有样本选择、图层加载、region 高亮、重置视角与打开结果文件夹入口均保留。

## 验收

- PCA Score 表的父面板位于右侧上方，3D viewer 位于右侧下方，二者不再属于左侧信息栏。
- 左侧不包含 PCA Score 表，且自身可垂直滚动。
- 测试覆盖布局容器、默认分配与已有 PCA/3D 交互。
