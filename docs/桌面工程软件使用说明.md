# 耳廓工程分析桌面软件使用说明

## 安装与启动

在 Windows 10/11 上运行 `scripts\build_desktop.ps1` 生成 `dist\耳廓工程分析`。双击其中的 `耳廓工程分析.exe` 启动；开发环境也可运行：

```powershell
python -m desktop_app
```

## 默认流程

1. 新建一个空的项目工作目录。
2. 选择 PLY 网格目录、地标 CSV 目录、`region_table.csv` 与 `edge_control_points.csv`。
3. 软件复制输入，不会改写原文件；自动校验样本配对和配置字段。
4. 校验通过后调整少量阈值，点击“一键开始分析”。
5. 在运行页查看阶段、样本事件，按需要暂停、继续或取消。
6. 完成后进入结果复核，查看 CSV、日志、QC 证据与可用三维层。

## 恢复与专家模式

专家模式只显示已通过完整性校验的父 attempt 输出。每次 Weld、对齐或 PCA 重跑都会新建 child attempt；父 artifacts 仅被读取，绝不会覆盖。恢复 manifest 记录父 attempt、来源阶段、父 manifest SHA-256 和退出状态。

## 保留产物

项目目录保留 CSV、PLY、OBJ、STL、PNG、manifest、JSONL 事件和日志。桌面运行使用隔离 artifacts 根目录；CLI 仍可继续使用 README 中的既有命令。
