## 范围

### 现行规则（需要更新）

- `ear_param/run_artifacts.py` 的默认参考耳目录令牌；
- `scripts/run_full_pipeline.py` 的 CLI 帮助；
- 桌面端参数页的参考耳提示；
- README、W2/W3 技术说明、整耳坐标说明与桌面软件使用说明中的正式命令、输出目录示例和当前规则说明；
- 对应的默认产物目录回归测试。

### 历史记录（保留，但需标注）

旧数据集中的 `T076_L` 样本、既往 QC 表、W3 PCA 数值结果，以及
`GPA与T076固定参考耳PCA对比.md` 是可追溯的历史证据，不能替换为新的 MQ 样本。
这些内容会增加“历史验证记录”说明，避免被误认为当前运行规范。

## 规则与数据流

固定参考耳模式下，CLI 使用：

```powershell
--alignment-mode fixed-reference --reference-sample MQ_S076L
```

未显式提供参考耳、但需要形成参考耳目录名的兼容路径，默认生成：

```text
aligned_reference_MQ_S076L/
pca_reference_MQ_S076L_r24/
```

GPA 路线保持不变：`--alignment-mode gpa`，且不传 `--reference-sample`。
