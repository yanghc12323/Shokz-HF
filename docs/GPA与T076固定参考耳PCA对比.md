# GPA 与 T076 固定参考耳 PCA 对比

更新时间：2026-07-14

## 1. 比较目的

验证刚体对齐目标的选择是否会实质影响 W3 PCA。比较两条互不混合的路径：

```text
Weld repaired 整耳 -> GPA 对齐 -> output/w3_pca_r24/
Weld repaired 整耳 -> T076_L 固定参考耳对齐 -> output/w3_pca_reference_r24/
```

两条路径都只做旋转和平移，不缩放、不镜像、不改变全局点序或面拓扑。固定参考耳为 `T076_L`，对齐 landmark 为 `L7、L13、L15、L26`，PCA 阈值均为 75%。

## 2. 可比样本范围

原始输入目录目前有 28 个 mesh/landmark 完整配对的左耳样本。但本次比较只能使用已经完成 W2 salvage、Weld 且通过 PCA 门禁的 11 个样本：

```text
T013_L, T066_L, T068_L, T069_L, T076_L, T077_L,
T078_L, T088_L, T094_L, T097_L, T099_L
```

因此，本文件验证的是两种对齐标准在当前 11 个合格样本上的稳定性，不是 28 个样本的最终人群结论。其余样本必须先完成 remesh、salvage、Weld 和对齐门禁，才可以进入下一轮正式比较。

## 3. 结果

### 3.1 方差解释率

| 主成分 | GPA | T076 固定参考耳 |
|---|---:|---:|
| PC1 | 36.3807% | 36.8594% |
| PC2 | 21.7007% | 21.4106% |
| PC3 | 17.2656% | 17.0438% |
| 前三项累计 | 75.3470% | 75.3138% |

两条路径均在 PC3 首次达到 75% 阈值，均保留 3 个主成分。累计解释率仅相差 0.0332 个百分点。

### 3.2 平均耳

将固定参考耳 PCA 的平均耳再做一次最佳全局刚体对齐到 GPA 平均耳后：

```text
顶点 RMS 距离：0.00855 mm
最大顶点距离：0.02098 mm
```

两种平均耳在当前样本上的差异远小于毫米量级，外形上可视为高度一致。

### 3.3 PC1 与 PC2 形态

将固定参考耳的主成分位移方向旋转到 GPA 坐标系后，位移场余弦相似度为：

| 对应主成分 | 余弦相似度 |
|---|---:|
| GPA PC1 vs 固定参考耳 PC1 | 0.999395 |
| GPA PC2 vs 固定参考耳 PC2 | 0.999627 |
| GPA PC3 vs 固定参考耳 PC3 | 0.999556 |

交叉对应的绝对相似度均不超过 0.021，说明 PC 顺序没有发生混合。前三个 PC 子空间的三个相似度奇异值为 `0.999963、0.999902、0.999680`。注意 PCA 主成分正负号本身可任意翻转，本次两条路径的符号恰好一致。

### 3.4 样本 scores 稳定性

同名 PC scores 的 Pearson 相关系数：

```text
PC1: 0.999707
PC2: 0.999594
PC3: 0.999568
```

同名 PC scores 的 Spearman 排名相关系数：

```text
PC1: 1.000000
PC2: 0.990909
PC3: 0.990909
```

因此，各样本在 PC 空间中的相对排序和主要位置几乎不受本次对齐标准选择影响。

## 4. 结论与使用规则

当前 11 个合格样本的实证结果支持以下判断：只要使用同一套稳定的刚体对齐规则，GPA 与 T076 固定参考耳对 PCA 的影响很小。

- 群体平均耳、PC 模式和统计主结果优先使用 GPA 路径。
- 工程坐标展示、尺寸测量和跨批次复现可使用 T076 固定参考耳路径。
- 两条路径的 CSV、scores、components 和平均耳不得混合进同一次 PCA。
- 样本扩充到 28 个样本的合格子集后，必须用同一比较方法重新验证一次；不能直接把当前 11 样本结论外推为最终总体结论。
