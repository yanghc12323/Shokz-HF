# 整耳 PLY 的 Geomagic 蓝色外侧朝向设计

## 目标

将整耳拼接阶段导出的 `*_whole_ear_welded.ply` 统一为：在当前 Geomagic 显示约定下，耳廓外侧为蓝色。修复只调整三角面顶点绕序，不改变任何几何坐标、区域拼接、Weld/QC 判定或 PCA 数值。

## 根因

现有整耳阶段会对相邻三角面的绕序做局部一致化，以消除相邻面正反交错；但每个连通分量的初始面未规定全局正反方向。因此，即便局部一致，整耳仍可能整体反向，导致 Geomagic 将耳廓外侧显示为黄色。

## 方案

在 `assemble_whole_ear` 中保留既有的局部绕序一致化，然后对该结果的每一个三角面交换 `global_v1` 与 `global_v2`。这一固定的全局反转以当前 Geomagic 的显示方向为标准，使耳廓外侧显示蓝色。

输出的 whole-ear CSV、PLY 和 Weld QC 图均继续使用同一份反转后的面表。增加汇总字段，明确记录已应用 Geomagic 蓝色外侧方向策略及反转的面数。

## 不在范围内

- 不改变顶点坐标、区域点、面集合、区域表、重网格或拼接阈值。
- 不改变 CLI 参数或桌面软件界面。
- 不对原始区域 PLY 或 remesh 输出施加反转；仅影响 whole-ear 输出。
- 不以源网格法线或空间坐标猜测“外侧”，避免引入数据相关且不稳定的判断。

## 验收与测试

1. 全局反转前后，每个面的无序顶点集合完全相同，顶点表逐值不变。
2. 相邻面的局部绕序一致性保持不变。
3. 导出的 PLY 面表与 `*_whole_ear_faces.csv` 完全一致。
4. Whole-ear 相关单元与导出回归测试通过；PCA 输入点坐标保持不变。

## 使用影响

代码更新后，需从“整耳拼接”阶段重新生成结果；若要让后续对齐、平均耳、PCA 目录的面表保持同一版本，建议继续重跑其后阶段。历史 PLY 文件本身不会被自动修改。
